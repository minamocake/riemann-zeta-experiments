# CGdL reproduction experiments (Research B)

Reproduction of the pair-correlation benchmark of Chirre-Gonçalves-de Laat (arXiv:1810.08843v2) with
the Gaussian-polynomial family. Everything here is a numerical candidate unless a certificate says
otherwise; nothing here changes `results/registry.yaml`. Every use for zeta zeros assumes RH.

|---|---|---|
| `b2_mini/` | `run_b2_mini.py` (needs cvxpy) | `b2_mini/results/b2_mini_results.json` |
